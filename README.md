# 🪙 소원의 연못

QR을 찍고, 내가 꾸민 동전을 연못에 던져 소원을 비는 3D 게임. 햇살 가득한 바로크 분수 광장(흰 대리석 궁전, 쏟아지는 폭포, 청록빛 물, 무지개)에서 여러 사람이 던진 동전이 연못 바닥에 계속 쌓여요.

- **연못 화면** (`index.html`): TV·모니터에 띄워 두는 화면. 드래그로 둘러보고 휠·핀치로 확대, 가만히 두면 천천히 혼자 둘러봐요. QR 카드는 접을 수 있어요. QR이 떠 있고, 누가 던지든 동전이 실시간으로 날아와 퐁당 빠지고 바닥에 쌓여요. 오른쪽 아래 QR, 왼쪽에는 🎉 소원 성취 게시판이 있어요.
- **던지는 폰** (`coin.html`): QR로 들어와서 닉네임 → 동전 꾸미기 → 소원 쓰기 → **3번 던지기** → 결과. 폰에서도 동전이 날아가 연못에 빠지는 장면이 3D로 보여요.

GitHub Pages(정적 호스팅) + Firebase Realtime Database(실시간 연동·동전 보관)로 동작합니다.

## 플레이 방법

1. 연못 화면을 열어 두고, 폰 카메라로 QR을 찍어요.
2. **동전 꾸미기**: 재질(금·은·동·로즈·옥), 가운데 그림(이모지), 앞·뒷면 글자(4자), 테두리 무늬.
3. **소원 쓰기** (40자). "성공하면 익명으로 게시판에 올리기"가 기본으로 켜져 있어요.
4. **폰을 앞으로 휙 휘둘러** 던져요. 세게 휘두를수록 멀리 가고, **좌우로 기울여 조준**해요(화면 아래 금빛 점). 살짝 흔들면 손 안에서 동전이 달그락거려요. 오른쪽 위 **☝️ 손가락으로 던지기**를 켜면 위로 스와이프해서 던질 수 있어요. 동작 센서가 없거나 권한을 거부하면 자동으로 손가락 모드가 돼요. 바람(→ ←)도 불어요.
   - 🐢 **귀여운 대리석 거북** 등에 올라가거나 🏺 **금테 항아리**에 쏙 들어가면 소원 성취 / 💧 연못에 빠지면 목표에 가까울수록 점수 / 대리석 테두리·궁전 벽에 맞으면 "깡!"
   - 성공하면 도파민 팡팡: 불꽃놀이·금빛 충격파·색종이·금빛 비·물줄기 솟구침·무지개 반짝·화면 번쩍·큰 "소원 성취!" 도장·팡파르·박수 소리. 연못 화면에서는 성공한 사람이 만세하며 콩콩 뛰고, 다른 사람들은 그쪽을 보며 👏 박수를 쳐요. 연못 둘레 캐릭터는 던질 때 팔을 뒤로 젖혔다 머리 위로 휙 휘둘러 던져요.
5. 거북 등이나 항아리에 하나라도 올리면 **"소원이 이루어집니다!!"**, 아니면 확률 대신 "다시 해보세요!"로 희망을 줘요. 거북 등이나 항아리에 성공하면 소원이 **익명으로** 성취 게시판에 올라가고, 다른 사람들이 ❤️ 하트와 👏 응원을 보낼 수 있어요 (한 사람당 소원 하나에 한 번씩). 하트·응원이 오면 내 폰에 알림이 떠요. 연못 화면의 성취 게시판은 －/＋로 접었다 펼 수 있어요. 항아리에 들어간 동전은 입구 가까이 쌓인 금화 더미 위에 보여요.

> 데스크톱 테스트: 던지기 화면에서 **스페이스바**를 누르면 무작위로 던져요. 연못 화면 콘솔에서 `testThrow()`로 테스트 동전을 날릴 수 있어요.
> 연못 화면 콘솔: `testCrowd(6)`로 가짜 접속자를 세우고 `testThrow(0.55, -0.58, 'test0')`처럼 uid를 넣으면 그 사람이 팔을 휘둘러 던져요. `testSlow(0.25)`로 슬로 모션, `testSlow(1)`로 원래대로.

## 1. Firebase 설정

1. [Firebase 콘솔](https://console.firebase.google.com) → **프로젝트 추가** (이 게임 전용 프로젝트 권장).
2. 빌드 → **Realtime Database** → 데이터베이스 만들기 (위치는 싱가포르 `asia-southeast1` 추천, "잠금 모드"로 시작해도 OK).
3. Realtime Database → **규칙** 탭에 [`database.rules.json`](database.rules.json) 내용을 붙여넣고 **게시**.
4. 빌드 → **Authentication** → 시작하기 → 로그인 방법에서 **익명** 사용 설정.
5. 프로젝트 설정(⚙️) → 내 앱 → **웹 앱(</>) 추가** → `firebaseConfig` 값을 [`js/firebase-config.js`](js/firebase-config.js)에 붙여넣기 (`databaseURL` 필수).

> Firebase 웹 설정값(apiKey 등)은 공개돼도 되는 값이에요. 보안은 DB 규칙으로 지킵니다.

DB 규칙이 지키는 것:
- 동전·소원은 **새로 쓰기만** 가능 (수정·삭제 불가). 동전은 계속 쌓여요.
- 한 사람(익명 로그인 uid)당 1.2초에 동전 1개 (도배 방지).
- 닉네임 10자, 각인 4자, 소원 40자 제한. 게시판에는 거북·항아리 성공만 올라감.
- 하트·응원·신고는 한 사람이 소원 하나에 한 번 (`wishHearts`/`wishCheers`/`wishReports`에 기록, 소원에는 숫자 `h`/`n`/`r`만). 신고 3개면 게시판에서 숨김.
- 접속 정보(닉네임·동전 디자인)도 길이 제한.

데이터 아끼기:
- 연못 화면은 최근 동전 300개, 폰은 60개만 처음에 받아 와요. 이후엔 새 동전만 받아요.
- 응원 목록 대신 숫자만 저장해서 소원 목록이 가볍게 유지돼요. 접속자는 바뀐 사람만 받아요.
- 폰을 30초 넘게 다른 앱에 두면 연결을 끊고(접속자 캐릭터도 퇴장), 돌아오면 다시 연결해요.
- 무료(Spark) 요금제는 **동시 접속 100개**까지예요. 행사처럼 사람이 많이 몰리면 Blaze(종량제)로 바꾸세요.

## 2. GitHub Pages 배포

```bash
git push -u origin main
```

저장소 → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
잠시 후 `https://dopasharp.github.io/wish-pond/` 에서 열려요. 연못 화면의 QR은 `coin.html` 주소를 자동으로 가리켜요.

## 로컬 테스트 (Firebase 없이)

`firebase-config.js`가 비어 있으면(또는 주소에 `?local`) **로컬 테스트 모드**예요. 같은 브라우저의 탭끼리 localStorage + BroadcastChannel로 연동돼요.

```bash
python3 -m http.server 4190
```

`http://localhost:4190/` (연못) 탭과 `http://localhost:4190/coin.html` (폰) 탭을 같이 열고 던져 보세요.


## 도파# 브랜드 프레임

`dopasharp/` 폴더는 모든 dopa.shap 게임 저장소에 **똑같이** 복사해 쓰는 공통 디자인 시스템입니다. 원본은 `soju-game/dopasharp/`이고, 이 저장소의 `dopasharp.js`에는 게임 목록에 `wish-pond`(GAME 009 / WISH)를 추가해 두었어요. 원본과 다른 저장소들, 허브의 `games.js`에도 같은 줄을 넣어 주세요.
